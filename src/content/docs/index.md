キャップ野球の試合を CAP-SCOREBOOK で記録する人（スコアラー）のための手引きです。初めて記録する人が、試合の作成から成績の確定までを1人で進められるように書いています。

成績を見るだけの人は、このマニュアルを読む必要はありません。

> 下書きです。画面の文言は、公開前の新しい画面（試合詳細・スタメン設定・打席入力のデザイン変更後）に合わせています。「確認中」と書いた箇所は、管理人に確かめてから書き直します。

## 読む順番

試合の当日までに、1〜3を一度読んでください。4〜7は、試合中に困ったときに開くページです。

1. [試合の前に用意するもの](./prepare/)
2. [試合を作ってスタメンを決める](./create-game/)
3. [1打席を記録する](./at-bat/)
4. [選手交代と守備位置の変更](./substitution/)
5. [間違えたときの直し方](./fix/)
6. [試合を終える（成績の確定）](./finish/)
7. [困ったとき](./trouble/)

## 先に覚える3つの決まり

1. **走者・アウト・得点・自責点は入力しません。** 記録者が入れるのは、打席の結果とバッテリーエラー（暴投・捕逸・ボーク）だけです。残りはアプリが計算します。
2. **選手交代は、次の打席を保存する前に入れます。** 交代を入れずに打席を保存すると、前の投手や打者の成績として記録されます。
3. **試合が終わったら「確定する」をタップします。** 確定しない試合は、順位表にも打率・防御率にも入りません。確定した後に打席を直したときは、「ロック解除」→「確定する」をもう一度行います。部分編集で直したときは、その前に最後の打席を保存し直します。

## このマニュアルで使う言葉

| 言葉 | 意味 |
|---|---|
| 記録者 | 試合を入力する人。試合を作った人と、共同編集の許可をもらった人 |
| 管理人 | CAP-SCOREBOOK を運営している人。試合や選手の削除は管理人にしかできません |
| 試合詳細 | 1試合のスコアボードと成績を表示するページ |
| 記録者メニュー | 試合詳細のスコアボードの下に表示されるボタンの列。記録者にだけ表示されます |
| バッテリーエラー | 暴投（WP）・捕逸（PB）・ボーク（BK）の3つ |
