這是寫給用 CAP-SCOREBOOK 記錄瓶蓋棒球比賽的人（記錄員）的指南。寫法是讓第一次記錄的人，能獨自完成從建立比賽到確定成績的所有步驟。

只查看成績的人，不需要閱讀本手冊。

> 本文為草稿。畫面上的文字，以尚未公開的新畫面（比賽詳情、先發名單設定、打席輸入的設計變更後）為準。標示「確認中」的地方，會在向管理員確認後改寫。

## 閱讀順序

比賽當天之前，請把1～3讀過一遍。4～7是比賽中遇到問題時查閱的頁面。

1. [比賽前要準備的事項](./prepare/)
2. [建立比賽並排定先發名單](./create-game/)
3. [記錄1個打席](./at-bat/)
4. [球員替換與守備位置的變更](./substitution/)
5. [出錯時的修改方法](./fix/)
6. [結束比賽（確定成績）](./finish/)
7. [遇到問題時](./trouble/)

## 先記住3條規則

1. **不輸入跑者、出局、得分、自責分。** 記錄員只輸入打席的結果和投捕失誤（暴投、捕逸、投手犯規）。其餘由應用程式計算。
2. **球員替換要在儲存下一個打席之前輸入。** 沒有輸入替換就儲存打席，會被記成前一位投手或打者的成績。
3. **比賽結束後，點選「確定する」（確定成績）。** 未確定的比賽，不會計入排名表，也不會計入打擊率、防禦率。確定之後又修改打席時，要再做一次「ロック解除」（解除鎖定）→「確定する」。用部分編輯修改時，要在這之前重新儲存最後一個打席。

## 本手冊使用的詞彙

| 詞彙 | 意思 |
|---|---|
| 記錄員 | 輸入比賽的人。包括建立比賽的人，以及取得共同編輯許可的人 |
| 管理員 | 營運 CAP-SCOREBOOK 的人。比賽和球員的刪除只有管理員能做 |
| 比賽詳情 | 顯示1場比賽的記分板和成績的頁面 |
| 記錄員選單 | 顯示在比賽詳情記分板下方的一排按鈕。只對記錄員顯示 |
| 投捕失誤 | 暴投（WP）、捕逸（PB）、投手犯規（BK）這3種 |
