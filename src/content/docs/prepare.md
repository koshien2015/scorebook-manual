---
title: 試合の前に用意するもの
---

試合の当日に慌てないよう、前日までに次の4つを済ませます。

- ログインできること
- 出場する選手が全員登録されていること
- 両チームが登録されていること
- 大会が登録されていて、両チームが参加チームに入っていること

## ログインする

必要なのは Google か Twitter のアカウントです。

1. トップページのメニューから「ログイン」を開きます。「新規登録 / ログイン」の画面が表示されます。
2. Google のボタンか「Twitterでログイン」をタップします。その場で登録が終わります。

登録の前に、画面の「必ずお読みください」を読んでください。チームや選手を登録して使う場合は、**事前に管理人の許諾が必要**です。許諾のない登録は、削除されることがあります。

スコア作成者として表示される名前は、Google か Twitter のプロフィール名です。自分では変えられません。

## 選手を登録する

登録の前に、その選手がすでに登録されていないかを必ず確かめます。同じ選手を二重に登録すると、成績が2人に分かれます。利用者は選手を削除も統合もできないので、直すには管理人の作業が要ります。

1. メニューの「選手新規作成」を開きます。
2. 「チーム」にチーム名を入力し、表示された候補から選びます。
3. 「選手名」を入力します。入力中に「既存の選手」の候補が表示されます。同じ選手がいないかをここで確かめます。
4. 「投球」「打撃」を選びます。**初期値は左投げ・左打ちです。** 右の選手は必ず変えます。
5. 「登録」をタップします。「選手の登録が完了しました」と表示されます。

同じチームに同じ名前の選手がいると、ボタンが「重複のため登録不可」になり、登録できません。

選手の名前・所属・投打を変えられるのは、その選手を登録した人だけです。ほかの人が登録した選手を直したいときは、管理人に依頼してください。

## チームを登録する

1. メニューの「チーム新規作成」を開きます。
2. 「チーム名」を入力します。
3. 「登録」をタップします。「チームの登録が完了しました」と表示されます。

同じ名前のチームは登録できません。似た名前のチームがあると警告が表示されるので、同じチームでないかを確かめます。

**チームは、登録した後に名前を変えることも削除することもできません。** 入力を間違えたときは管理人に依頼します。

## 大会を登録する

すでに登録されている大会の試合を記録するなら、この節は読み飛ばして構いません。

1. メニューの「その他のメニュー」から「大会作成編集」を開きます。
2. 「リーグ新規追加」をタップします。
3. 次の項目を設定し、「登録」をタップします。

| 項目 | 何に使われるか |
|---|---|
| リーグ名 | 大会の表示名 |
| リーグのグループ(分類) | 通算成績に含めるかどうか。「所属なし(練習試合)」の大会は、通算成績などの多くの集計に入りません |
| 競技種別 | 「キャップ野球」か「キャップ野球以外」。全体成績の集計の対象を分けます |
| 成績の換算イニング数 | 防御率の計算（自責点 ÷ 投球回 × この値）と、勝利投手の規定投球回 |
| 大会共通タイブレーク設定 | タイブレークの回の最初に置くアウト数と走者。何回から始めるかは試合ごとに決めます |
| 参加チーム | スタメン設定でこの大会を選ぶと、ここに入れたチームだけが選べます |

新しく登録するときは、「競技種別」と「成績の換算イニング数」を、表示されている値のままでよい場合も一度選び直します。選び直さないと、値が空のまま送られます。

知っておくこと:

- 大会の設定は、後から変えると**過去の試合にも効きます**。たとえば換算イニング数を変えると、過去の試合の防御率も変わります。
- 大会を編集できるのは、その大会を登録した人だけです。
- 大会は削除できません。
- コールドゲームの点差は大会ごとに設定できません。全大会で同じ基準（1回15点差・2回10点差・3回7点差）です。
